# HR Analytics Dashboard (Power BI)

* Project Overview

This project focuses on analyzing employee data to understand workforce trends, attrition patterns, and performance insights.The dashboard transforms raw HR data into interactive visualizations that help in making data-driven HR decisions.

* Objectives
-Analyze employee headcount and workforce distribution

-Measure and monitor attrition rate

-Evaluate employee performance and satisfaction

-Identify key recruitment sources

-Provide actionable insights for HR decision-making

* Tools & Technologies
  
-Power BI

-Power Query (Data Cleaning & Transformation)

-DAX (Data Analysis Expressions)

-Data Visualization

* Key KPIs Created
  
-Total Headcount

-Active Employees

-Terminated Employees

-Attrition Rate (%)

-Total Salary

* Dashboard Features
  
-Interactive KPI cards for quick insights

-Department-wise and state-wise employee distribution

-Gender and marital status analysis

-Performance and satisfaction visualization

-Recruitment source analysis

-Dynamic slicers (Year, Department, Gender) for real-time filtering

* Key Insights
 
- Workforce Overview
  
Total Employees: 311

Active Employees: 207 (~67%)

Attrition Rate: ~33%

-Indicates a relatively high attrition level requiring attention)

- Department Analysis:Majority of employees belong to the Production department

 Gender Distribution:Female employees: ~57%,Male employees: ~43%

-Shows a relatively balanced workforce with slight female dominance

* Performance Insights
 
Most employees fall under “Fully Meets” category.Indicates stable overall performance

* Employee Satisfaction
 
Majority of employees show moderate to high satisfaction. However, attrition still exists → possible gap between satisfaction and retention

* Recruitment Source
 
Major hiring sources: Indeed, LinkedIn. Online platforms are the primary recruitment channels

* Business Recommendations
 
-Investigate high attrition areas (department, tenure, performance level)

-Improve onboarding and early employee engagement

-Evaluate hiring quality from different recruitment sources

-Focus on retention strategies for high-performing employees

-Introduce training programs for low-performing employees

* Conclusion

This dashboard demonstrates how raw HR data can be transformed into meaningful insights using Power BI.It enables HR teams to monitor workforce trends, identify challenges, and make informed decisions to improve employee retention and performance.
